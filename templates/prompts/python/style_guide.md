# Python 代码风格指南

_（根据项目实际代码风格调整）_

## 格式化

- 遵循项目已有格式化工具；无约定时优先使用 Black/Ruff 兼容风格
- 行宽遵循项目配置；无配置时控制在 88-100 字符
- import 顺序：标准库、第三方库、本项目模块

## 命名

- 模块、函数、变量：snake_case
- 类：PascalCase
- 常量：UPPER_SNAKE_CASE
- 私有实现使用单下划线前缀

## 类型

- 新增公共函数应提供类型标注
- 复杂返回值优先使用 dataclass、TypedDict 或明确的领域对象
- 避免裸 dict/list 在多层调用中传递业务结构

## 错误处理

- 捕获具体异常，避免无条件吞掉异常
- 边界层负责把底层异常转换为面向调用方的错误
- 日志包含诊断上下文，但不输出敏感数据

## 测试

- 业务规则使用单元测试覆盖
- 文件、网络、数据库等外部依赖使用 fixture、mock 或集成测试隔离
