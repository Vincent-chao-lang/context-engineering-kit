# TypeScript 代码风格指南

_（根据项目实际代码风格调整）_

## 格式化

- 缩进：2 空格
- 行宽：不超过 120 字符
- 多行对象、数组和参数保留尾随逗号

## 命名

- 变量/函数：camelCase
- 组件/类/类型：PascalCase
- 常量：UPPER_SNAKE_CASE
- 文件：优先使用项目既有约定；无约定时使用 kebab-case

## 类型

- 公共数据结构优先使用 interface
- 联合类型、映射类型、工具类型使用 type
- 避免 any；必要时优先使用 unknown 并在边界收窄
- 共享类型放在项目既有 types 或 domain 目录中

## 组件和函数

- 一个文件只放一个主要组件、类或模块入口
- 状态提升到必要的最低层级
- 副作用集中管理，避免隐藏在渲染或纯计算逻辑中

## 注释

- 不写重复代码含义的 WHAT 注释
- 只写解释取舍、约束和非显而易见原因的 WHY 注释
