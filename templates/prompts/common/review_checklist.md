# 代码审查清单

每次提交代码前检查：

## 功能正确性
- [ ] 核心逻辑是否正确
- [ ] 边界条件是否处理
- [ ] 错误路径是否覆盖

## 代码质量
- [ ] 命名是否清晰
- [ ] 是否有重复代码可提取
- [ ] 函数、组件或模块是否职责单一

## 安全性
- [ ] 用户输入是否验证
- [ ] 敏感数据是否加密、脱敏或避免输出
- [ ] API Key、Token、密码是否未暴露在代码和日志中

## 性能
- [ ] 是否有不必要的重复计算或重复 IO
- [ ] 大列表、大文件或批量任务是否有规模化处理方案
- [ ] 异步操作是否有错误处理和超时策略

## 兼容性
- [ ] 是否影响现有功能
- [ ] 数据结构变更是否向后兼容
- [ ] 配置、环境变量或迁移步骤是否有说明
