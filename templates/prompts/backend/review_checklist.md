# 后端审查清单

后端、API、任务队列或数据层变更提交前检查：

## API 和契约
- [ ] 请求、响应、错误码是否清晰且向后兼容
- [ ] 输入校验是否覆盖边界值和恶意输入
- [ ] 幂等性、重试和超时语义是否明确

## 数据
- [ ] 数据库迁移是否可回滚或有恢复方案
- [ ] 索引、查询计划或批量处理是否考虑数据规模
- [ ] 事务边界是否正确

## 安全
- [ ] 认证和授权是否在服务端强制执行
- [ ] 敏感字段是否避免日志输出
- [ ] 文件、URL、命令、SQL 等注入风险是否处理

## 运维
- [ ] 关键路径是否有日志、指标或错误追踪
- [ ] 配置项和环境变量是否有文档
- [ ] 后台任务是否有失败重试、死信或人工处理路径
